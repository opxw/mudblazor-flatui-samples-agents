# Portrait profile images

FlatProfileAvatar.Portrait is opt-in and defaults false. True uses a rounded 3:4 frame with contain and centered image; Size defines width. FlatProfileListItem.PortraitAvatar forwards it. Preserve source pixels in producer thumbnails; contain cannot recover previously cropped data. Neutral surface, initials/error fallback and default circle behavior remain. Both properties are verified in the official NuGet 2.1.33 DLL; older upstream unpublished-candidate notes do not describe this consumer baseline.
