# Charts P0–P2

The shared `/charts` page retains all eleven MudBlazor9.9 ChartTypes. `ChartInteractionPreview` demonstrates the full period/filter/state/drill-down workflow once; gallery cards remain compact, with native hide-series legends and source tables.

- P0: brighter blue/teal palette, theme foreground SVG labels, WidgetGap token, unclipped card/chart wrappers and wrapping legends. Tables own their horizontal scroller on phones; numeric cells stay intact. No document-wide horizontal scrolling is intended.
- P1: every chart has a semantic captioned source table generated from its actual ChartData, including dates, XY coordinates and Sankey links. Gallery tables intentionally contain the complete source even when a legend hides a series. Mutable series are per-page instances, never static across users. Interactive Line/Bar switches synthetic H1/H2 periods, filters chart and table together, and uses FlatWidget for loading/empty/error/retry and update time.
- P2: table ValueFormat and Unit are host parameters. Interactive numeric axes/table/detail use configured culture, currency is an explicit code (no currency conversion), dates use host formats and timestamp uses configured timezone. Gallery data is synthetic and generic units are not business metrics. Point-index chart selection and an accessible category selector return period/category/visible values to the local sample handler; the chart API does not identify a unique series, so no series is guessed.
- Export is hidden unless the demo host flag is enabled and checked again in the handler. Print/export buttons record scoped request intent only: no file is generated, printer invoked, or server authorization granted. Production hosts must replace these handlers with authenticated data/export services and the existing print adapter. Print CSS hides interactive controls/code while retaining chart/data content; this is not native printing certification.

Regression: tests/responsive/charts-readiness.spec.ts. Preview must pass scripts/test-preview-assets.ps1 before sharing; source builds can stale older running previews. Browser evidence does not certify MAUI/physical print, screen readers, or all long/localized labels and tooltip edge cases.
