Inspect upstream samples when selecting a new layout, then preserve the local NuGet-only/Exact Sample contract.

Whenever adding or changing any UI element, even a label/icon, read docs/UI-NON-OVERLAP.md and apply its acceptance gate. Inspect surrounding widgets and dynamic states; choose one spacing owner, allow wrapping/intrinsic heights, reserve helper/error/action space and verify actual geometry in a current desktop/mobile preview. Preserve deliberate edge-to-edge groups and documented overlays, never conceal collisions with arbitrary clipping. Report missing theme/native proof.

For adjacent dashboard widgets use Home.razor's dashboard-widget-stack: 16px desktop/12px mobile block spacing and 8px caption gap. Verify measured inter-widget gaps, not just CSS declarations. Keep outer spacing owned by composition and avoid duplicate margins in reusable widgets.

For a module map select opx.page.navigation.sitemap and read docs/SITEMAP.md. Reuse FlatDynamicMenuBuilder and package URL normalization; preserve original host IDs, permission-filtered input, ancestor search and native scrolling. The synthetic catalog adapter hashes ancestry only because its source has no IDs. Test links and Back to the searched map without inventing Bottom submenu entries.

For Profile Settings use opx.page.account.profile-settings, ProfileSettings.razor and docs/PROFILE-SETTINGS.md. Compare independent snapshots including skills/links/photo/experience/privacy; gate section changes and Back with FlatUnsavedChangesGuard. Keep completion host-supplied and password changes in authenticated host services. Preserve global variants and FlatPage keyboard infrastructure; browser proof does not certify native IME visibility.

For media-object layouts read docs/MEDIA-OBJECT.md and MediaObjectPreview in ComponentsGallery. Reuse FlatMediaObject with logical Start/End and Top/Center/Bottom. Test intrinsic media, no-media state, encoded titles, nested wrapping and RTL; preserve FlatProfileAvatar and avoid forcing row heights or adding scroll handlers.

For item/asset/collection detail requests, select opx.page.commerce.item-detail and read docs/ITEM-DETAIL.md plus shared ItemDetail.razor. Reuse FlatProductDetail slots, local or authorized host media, theme controls and existing navigation history. Verify thumbnail/Previous/Next changes, optional reviews/commerce, encoded submissions and mobile natural scrolling. Scope SVG sizing to artwork so it never enlarges Mud icons. Never report an intent callback as a granted permission, bid, order or payment.

For a left/right anchored dialog with typed data exchange, use `FlatSidePanel<TData>` and read `docs/SIDE-PANEL.md`. Reuse the existing modal lifecycle instead of a second Back/overlay system. Require host-owned independent draft creation; only confirmed results carry data. Validate physical left/right anchors, RTL, responsive width, body-only scrolling and Apply/Cancel/Back separately from native device proof.

For time-of-day masking use `FlatTimePicker` and read `docs/TIME-PICKER.md`; Calendar is the canonical integration. Format alone selects HH 24-hour versus hh 12-hour AM/PM and optional seconds. Keep typed invalid/partial input from emitting a replacement host value, preserve format-only changes, and test midnight/noon, mask editing, seconds, Apply/Cancel and disabled/read-only states. Do not substitute duration or timezone semantics or claim native picker/IME proof from browser tests.

For Filled/Standard/Outlined spacing or SimpleBar-like sidebar requests, read the Input rhythm and sidebar scrolling section in `docs/DISPLAY-SETTINGS.md` and use the shared `/crud-simple?preview=input-rhythm` preview. Keep canonical form gaps at 12px (10px at <=600px), helper/error top gap at 4px and inline inset at 10px. Align field starts and avoid duplicate margins on nested select wrappers; preserve each variant's floating-label reservation and intrinsic multiline height instead of forcing equal control heights. Check the final computed cascade, including later grid gap rules. Verify textbox/select alignment, wrapped helper/error text and no horizontal overflow in desktop/mobile Light/Dark screenshots.

Sidebar `.drawer-scroll` uses a progressive overlay thumb inside `.drawer-scroll-frame`, while the content keeps native scrolling. Preserve hover/focus/scroll visibility, mouse-thumb dragging, resize/content measurement, disposal and native fallback when JS is unavailable or forced-colors is active. Measure the frame rather than a hidden track to avoid a permanently zero-sized thumb. Do not install SimpleBar, intercept content gestures, or apply sidebar thin-scrollbar styling to data grids. Validate actual scroll movement, thumb dragging and idle hiding; keep native-device proof boundaries explicit.
